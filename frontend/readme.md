🌟 Sobre o Projeto
O SOL é um sistema inovador de musicoterapia assistida por inteligência artificial, desenvolvido para proporcionar experiências musicais personalizadas baseadas no estado emocional do usuário. Através de uma interface moderna e intuitiva, o sistema oferece playlists terapêuticas adaptadas às necessidades emocionais individuais.
✨ Funcionalidades Principais
🔐 Tela de Login

Interface acolhedora com identidade visual do SOL
Campo para nome do usuário
Design responsivo com gradientes vibrantes
Validação de entrada intuitiva

🎼 Preferências Musicais

Seleção de múltiplos gêneros musicais

Rock, Pop, MPB, Sertanejo, Eletrônica, Jazz, Clássica, Reggae

🚀 Como Executar
Pré-requisitos

Node.js 16+ instalado
npm ou yarn como gerenciador de pacotes

Instalação
bash# Clone o repositório
git clone [url-do-repositorio]

# Navegue para o diretório do frontend
cd frontend

# Instale as dependências
npm install
# ou
yarn install
Execução em Desenvolvimento
bash# Inicie o servidor de desenvolvimento
npm run dev
# ou
yarn dev
Build para Produção
bash# Gere os arquivos otimizados para produção
npm run build
# ou
yarn build
