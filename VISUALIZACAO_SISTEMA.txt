│                        FLUXO DE DADOS (Exemplo Real)                        │
└─────────────────────────────────────────────────────────────────────────────┘

1️⃣ USER CLICA "CONECTAR SPOTIFY"
   ┌─────────┐
   │ Frontend│ → POST /api/spotify/auth/login (com JWT)
   └─────────┘
        ↓
   ┌──────────┐
   │  Backend │ → Gera URL + stateToken
   └──────────┘
        ↓
   ┌──────────┐
   │ Frontend │ → Redireciona para Spotify
   └──────────┘

2️⃣ USER FAZ LOGIN NO SPOTIFY
   ┌───────────┐
   │  Spotify  │ → Retorna code + state
   └───────────┘
        ↓
   ┌──────────┐
   │  Backend │ → Callback recebe code
   └──────────┘
        ↓
   ┌──────────┐     ┌────────────┐
   │  Backend │ --> │   Spotify  │ → POST /api/token
   └──────────┘     └────────────┘
        ↓
   ┌──────────┐     ┌────────┐
   │  Backend │ --> │   BD   │ → Salva tokens
   └──────────┘     └────────┘
        ↓
   ┌─────────┐
   │ Frontend│ → Volta para Playlist (botão agora ativo!)
   └─────────┘

3️⃣ USER CLICA PLAY
   ┌─────────┐
   │ Frontend│ → POST /api/spotify/play (com URI + deviceId)
   └─────────┘
        ↓
   ┌──────────┐
   │  Backend │ → Usa token do BD
   └──────────┘
        ↓
   ┌──────────┐     ┌───────────┐
   │  Backend │ --> │  Spotify  │ → PUT /v1/me/player/play
   └──────────┘     └───────────┘
        ↓
   🎵 MÚSICA TOCA NO NAVEGADOR!
